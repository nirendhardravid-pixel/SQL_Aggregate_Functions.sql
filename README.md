## SQL Aggregate Functions and Clauses

This file contains SQL practice queries covering aggregate functions and clauses used for data analysis.

### Aggregate Functions

* COUNT() – Counts rows.
* SUM() – Calculates the total.
* AVG() – Calculates the average.
* MIN() – Finds the minimum value.
* MAX() – Finds the maximum value.

### SQL Clauses

* WHERE – Filters rows based on conditions.
* GROUP BY – Groups rows with the same values.
* HAVING – Filters grouped results.
* ORDER BY – Sorts query results.
* LIMIT – Restricts the number of returned rows.

### Objective

To practice SQL aggregate functions and clauses to improve data analysis and database querying skills.
